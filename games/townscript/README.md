# Townscript 城痕

点一块地起楼，**邻居的形状决定它长成什么**。
连排屋、孤塔、拱廊、阶梯、内院、方场、灯塔、高楼、码头 —— 十种地标由上下文规则自动演化。

> 原创实现。玩法结构致敬「上下文生成」类城镇沙盒网页小游戏的通用范式
> （点一下就长出建筑、颜色与邻居决定形态、围出空地变成庭院、窄道变成拱廊），
> 代码、文案、数据、音效均为本仓库自研自绘，不含任何第三方素材。

## 玩法

| 机制 | 说明 |
| --- | --- |
| **起楼** | 左键点地块即起一块地基；再点同一格就叠高，最高 4 层；右键拆除 |
| **上下文规则** | 每块地基的形态由四邻推导：等高邻居→联排屋；无等高邻居→孤塔；左右临水上下有陆→拱廊；相邻差一阶→阶梯；四面高墙围住一格水→内院；2×2 同高→方场；细高塔身且与邻居颜色交替→灯塔；盖到四层→高楼；紧贴深海→码头 |
| **地志图鉴** | 10 种地标 × 2 条里程碑（初次建起 / 五度匠心）= 20 条收集物 |
| **工坊升级** | 拓地（海图变大）/ 调色（解锁 9 种配色）/ 勘测（标出下一处未发现地标）/ 营建（每块地基多产铜钱） |
| **地脉** | 每座岛有 3 处地脉（SVG 金色圆环标记），在上面建造铜钱 ×3 |
| **城镇代码** | 一串文本即可分享 / 还原整座城（`TS1-种子-高度-颜色`） |
| **每日岛屿** | 日期做种子，全服同一座岛、同一批地脉，方便互相比较 |
| **多语言** | 中文 / English / 日本語，右上角切换 |
| **本地存档** | 城镇与档案存 `localStorage`，刷新不丢；存档损坏时自动回退 |

### 为什么要「确定性」

岛屿形状、地脉位置、城镇代码全部由**同一个带种子的 PRNG**派生，
所以同一个种子必然长出同一座城 —— 城镇代码能互相分享，日挑战才能比较。

## 目录结构

```
townscript/
├── index.html          页面骨架
├── assets/
│   ├── app.css         样式（海岛黄昏主题，含移动端与 reduced-motion 适配）
│   ├── app.js          表现层：SVG 渲染 / 输入 / 音效 / 持久化
│   ├── data.js         9 种配色、10 种地标、里程碑、升级配置
│   └── i18n.js         zh / en / ja 文案
├── src/
│   └── logic.js        纯逻辑层（无 DOM 依赖，全部规则在此，可完整单测）
└── test/
    ├── logic.test.mjs  36 条单元测试
    ├── smoke.test.mjs  Playwright 浏览器冒烟测试
    └── helpers.mjs     静态服务器与 Playwright 装载辅助
```

**分层约定**：`src/logic.js` 不引用任何浏览器 API。岛屿生成（值噪声）、上下文规则、
命中检测、城镇代码编解码、勘测提示、图鉴与成就、存档全在这里，因此能被确定性地单测；
`assets/app.js` 只负责把城画到 SVG 上。

**渲染与命中检测共用同一套几何**（`VIEW.cell / VIEW.off / VIEW.gap`），
所以「看起来是哪一格」和「点下去算哪一格」永远一致。

## 运行

```bash
# 任选其一
python3 -m http.server 8080     # 然后访问 http://127.0.0.1:8080/games/townscript/
npx serve .
```

纯静态页面，无构建步骤、无运行时依赖、不引用任何外部 CDN。

## 测试

```bash
cd games/townscript
node --test "test/*.test.mjs"
```

- **单元测试**（36 条）：数据完整性、同种子同城 / 异种子异城、值噪声的确定性与连续性、
  网格尺寸随拓地变化、地脉数量与唯一性、每日岛屿一致、起楼 / 叠高 / 满层换色 / 越界拒绝、
  拆除不为负、**十种地标逐个用最小构造样本验证真的能造出来**、
  联排屋与孤塔互斥、高楼必须四层、灯塔必须异色、内院必须四面围墙、方场 2×2 的对称计数、
  命中检测（点方块 / 点上层 / 点空地）、**城镇代码往返一致 + 非法代码拒绝**、
  勘测提示只指向未发现地标且不改动城镇、图鉴里程碑与完成度、成就只解锁一次、
  工坊价格递增与满级 / 余额不足、存档往返与脏数据容错、边界输入。
- **冒烟测试**：真实 Chromium 中验证首屏渲染（9 色盘 / 10 条图鉴 / 4 项工坊 / 8 条成就）、
  点击起楼、叠高、右键拆除、拆除模式、数字键换色、每日岛屿切换、语言切换、
  刷新后进度保留、**城镇代码复制与还原**、非法代码不崩、控制台零报错，
  以及 390px 移动端视口无横向溢出。

需要 Playwright：`npm i -D playwright && npx playwright install chromium`（沙箱环境已预装）。

## 数据说明

- 地标形态由规则推导，**不是手工摆放的模型**：同一份规则在逻辑层与渲染层共用。
- 配色与地标图标为通用名词与通用符号的原创组合，不引用任何第三方美术资源。
- 三语名称为通用常识性标注；地标说明为原创撰写。
