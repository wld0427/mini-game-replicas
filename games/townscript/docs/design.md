# 功能设计 — Townscript 城痕

## 一句话定位

点一块海面起楼，**邻居的形状决定它长成什么**，把十种地标从上下文规则里钓出来。

## 核心玩法循环

```
选定一格 ──▶ 落子（起楼 / 叠高 / 涂色）
      │
      ▼
上下文规则按四邻推导形态 ──▶ 命中地标？──是──▶ 图鉴计数 +1、里程碑解锁、铜钱入账
      │                                        │
      │ 否                                     ▼
      └──────▶ 继续摆 ──────────────▶ 图鉴 / 工坊升级 / 城镇代码分享
```

- **落子**：`placeBlock()` 把格子高度 +1 并写入当前颜色；`removeBlock()` 拆掉一层。
- **推导**：`cellFacts()` 统计四邻（等高 / 更高 / 更低 / 空），`matchLandmarks()` 按十套规则判定。
- **结算**：`countLandmarks()` 取前后计数差得到「新发现的地标」，`applyEvent()` 写图鉴、解里程碑、发铜钱。
- **成长**：铜钱 → 工坊升级（拓地 / 调色 / 勘测 / 营建）。
- **分享**：整座城编码成一段文本（`TS2-…`），别人打开就能还原。

## 状态机

```
        ┌──────────── 自由岛（自由种子，存档 townscript-town-v1）────────────┐
        │                                                                    │
   ┌────┴─────┐   点格 / 叠高 / 涂色   ┌──────────┐   命中新地标   ┌────────┐ │
   │  空城态   │ ───────────────────▶ │  建造态   │ ────────────▶ │ 结算态 │ │
   │ (无建筑)  │ ◀─────────────────── │ (有建筑)  │ ◀──────────── │(图鉴++)│ │
   └──────────┘      拆除 / 清空        └──────────┘                └────────┘ │
        │                                                                    │
        │ 切换模式（不重建城，只换读哪一份存档）                              │
        ▼                                                                    │
   ┌──────────┐   当天的每日岛（种子=日期，存档 townscript-daily-<日期>）        │
   │ 每日岛态  │ ◀───────────────────────────────────────────────────────────────┘
   └──────────┘   （换天后是新的一座岛，同一天同一座）
```

关键：**模式切换不是「重新生成一座城」，而是「换读哪一份存档」**。
存量版本在这里直接把 `town` 换成新建的岛并立刻存档，把玩家成果覆盖掉 —— 本轮修掉。

## 数据结构

```js
Town = {
  seed: number,          // 岛屿种子（决定地形与地脉位置）
  expandLevel: number,   // 拓地等级（决定网格尺寸，**必须进存档**）
  cols, rows: number,    // 由 expandLevel 推导
  heights: number[],     // 每格高度 0–4
  colors: number[],      // 每格配色索引
  depth: number[],       // 每格水深 0–1（渲染用）
  veins: {key,c,r}[],    // 3 处地脉（种子决定）
  builds: number,        // 建造次数（**必须进存档**，否则「初基」会重复触发）
  removals: number,      // 拆除次数
}

Profile = {
  version, coins, totalEarned,
  upgrades: { expand, palette, survey, income },
  dex: { [landmarkId]: { count, firstAt } },
  achievements: { [key]: true },
  stats: { builds, removals, veinBuilds, discovered, bestHeight },
}
```

| 数据 | 位置 | 约束 |
| --- | --- | --- |
| 10 种地标 | `assets/data.js` `LANDMARKS` | 每种一条规则，规则实现在 `src/logic.js` |
| 2 条里程碑类型 | `assets/data.js` `MILESTONES` | 图鉴完成度 = 10 × 2 = 20 |
| 4 项工坊升级 | `assets/data.js` `UPGRADES` | `expand.max=3` → 网格 16×12 → 22×16 |
| 网格 | `assets/data.js` `GRID` | 基础 16 列 × 12 行，每级拓地 +2 列 +1 行 |
| 城镇代码 | `src/logic.js` `encodeTown()` | `TS2-种子-拓地-建造-拆除-高度-颜色`；兼容 `TS1` |

## 功能清单

| ID | 功能 | 说明 | 验收标准 |
| --- | --- | --- | --- |
| F-001 | 岛屿生成与确定性 | 值噪声 + 中心衰减生成地形，同种子必得同一座岛 | `createTown(42,0)` 连续两次调用的 `heights`/`depth`/`veins` 三个数组内容完全相等；`gridSize(0)` 等于 16 列 × 12 行 |
| F-002 | 上下文规则与十种地标 | 四邻统计推导十种形态 | 十种地标每一种都能被实际造出来（穷举可达性用例），`matchLandmarks()` 返回数组包含该 id |
| F-003 | 起楼与叠高 | 点一格起一块，再点叠高，最高 4 层 | `placeBlock()` 后该格高度由 0 变 1；连续 4 次后高度等于 4；第 5 次高度仍为 4（`MAX_HEIGHT` 封顶） |
| F-004 | 拆除与右键 | 右键或拆除模式拆掉一层，归零时清色 | `removeBlock()` 后高度由 2 变 1；归零后 `colors` 变为 0；`removals` 计数递增 |
| F-005 | 命中检测与渲染同几何 | 渲染与点选共用 `VIEW.cell/off/gap` | `blockRect(c,r,k)` 的宽高等于 `VIEW.cell - VIEW.gap`；对同一格，`hitTest()` 返回的列行与 `blockRect()` 的坐标自洽 |
| F-006 | 地志图鉴与里程碑 | 10 种 × 2 条 = 20 件收集物 | `applyEvent()` 触发 `house` 后 `dex.house.count` 由 0 变 1；第 5 次时 `house:adept` 里程碑解锁；`dexProgress().total` 等于 20 |
| F-007 | 铜钱经济与地脉倍率 | 每块地基 +1，地脉上 ×3，新地标额外 +12 | 建造 1 块后 `coins` 增量等于 `buildIncome(profile)`；地脉格建造的增量等于 3 倍；地脉上放置后 `stats.veinBuilds` 由 0 变 1 |
| F-008 | 工坊升级 | 拓地 / 调色 / 勘测 / 营建四项，价格随等级几何增长 | `upgradeCost('expand',0)` 等于 120；升级后 `upgrades.expand` 递增 1；拓地后 `gridSize()` 的列数比升级前多 2；铜钱不足时 `applyUpgrade()` 返回 null |
| F-009 | 城镇代码往返（含拓地） | 一段文本完整还原一座城 | 任意拓地等级 L（0–3）下，`decodeTown(encodeTown(town))` 返回的 `heights`/`colors` 逐格相等，且 `expandLevel`/`builds`/`removals` 与原值相等 |
| F-010 | 旧码兼容与非法码处理 | TS1 旧码仍可还原；非法输入返回 null | `decodeTown('TS1-…')`（合法旧码）返回非 null 且高度与旧码一致；`decodeTown('garbage')` 与 `decodeTown('')` 返回 null |
| F-011 | 模式切换不丢城 | 自由岛与每日岛各存各的，切换只换读哪一份 | 建造后切换模式再切回来，城镇代码字符串与切换前完全相等；切到每日模式时自由岛的存档内容不被修改 |
| F-012 | 每日岛与跨天重置 | 同一日期同一座岛；换天是新岛 | `createDailyTown('2026-11-27')` 两次调用结果相等；`createDailyTown('2026-11-28')` 的 `heights` 与前一天不相等 |
| F-013 | 模式与城镇持久化 | 刷新后模式状态与城都还在 | 刷新后 `aria-pressed` 的模式值与刷新前相等；刷新后 `.block` 数量与刷新前相等 |
| F-014 | 勘测提示 | 勘测升级后标出一处能造出新地标的空地 | `findHint()` 返回的格子高度为 0，且在该格落子后命中一个尚未发现的地标 |
| F-015 | 调色板解锁 | 初始 5 色，调色升级逐级解锁到 9 色 | `paletteSize()` 在 palette 等级 0 时等于 5，等级 4 时等于 9 |
| F-016 | 多语言与三语切换 | zh / en / ja 切换 | 切到 English 后商店标题文案变为英文；`html[lang]` 变为 `en` |
| F-017 | 音效反馈 | WebAudio 现场合成，落块声随层数变化 | 落子时创建的振荡器节点数不少于 1；不同层数对应不同频率 |
| F-018 | 存档脏数据回退 | 档案损坏时回退为初始状态，不抛异常 | 对非法 JSON 字符串反序列化后 `coins` 为 0 且 `dex` 键数为 10 |
| F-019 | 键盘与鼠标双输入 | 数字键 1–9 选色，左键落子，右键拆除 | 按 `3` 后当前配色索引变为 2；右键事件在 SVG 上触发拆除 |
| F-020 | 成就系统 | 按进度解锁且只解锁一次 | 首次建造后 `achievements` 中对应条目为 true 且解锁总数为 1；重复触发不再增加 |

## 难度契约

三档路线**用同一套规则代码跑**（`src/logic.js` 的 `placeBlock` / `removeBlock` / `countLandmarks` / `applyEvent`），
不允许为测试造假逻辑。三档分别对应同一批规则下的三种玩家行为。

| 路线 | 玩家行为 | 预期结果 | 如何判定（同一套规则） |
| --- | --- | --- | --- |
| **参考路线**（会玩的人能通关） | 按上下文规则有目的地摆：先摆 2×2 同高凑方场，再把孤立格叠到 3 层做孤塔，刻意给灯塔造出「细高 + 颜色交替」 | 10 种地标全部可达，图鉴能推到 20/20 | 穷举可达性用例：十种地标各有一种构造摆法，构造后 `matchLandmarks()` 命中对应 id |
| **弱化路线**（水平一般的人会挣扎或失败） | 随机乱点、不看邻居关系 | 靠运气能撞上一些地标，但凑不齐需要精确邻居关系的那几种（如灯塔要求「四邻只有一个等高邻居 + 颜色交替」），图鉴长期停在 20 件中的少数几件 | 随机摆放 200 次（固定种子）后，图鉴发现的地标种类数少于参考路线能拿满的 10 种 —— 用同一套 `placeBlock` + `countLandmarks` 统计 |
| **挂机路线**（完全不操作会明确失败） | 什么都不做 | 铜钱为 0、图鉴 0/20、建造次数 0 —— **挂机拿不到任何进度** | 空城状态下 `applyEvent` 从未被调用，`coins` 恒为 0、`dexProgress().done` 恒为 0；且 `buildIncome` 只在 `placeBlock` 后经 `doBuild` 发放，不存在时间驱动的被动收入 |

**样本量说明**：随机路线的「200 次」指 200 次落子（固定种子），而不是 200 局；
每次落子都会走完整的 `placeBlock` → `countLandmarks` → `applyEvent` 链路，
因此统计到的就是玩家真实能看到的地标集合。

## 边界与异常

| 情况 | 预期行为 |
| --- | --- |
| 在同一格连点超过 4 层 | 高度封顶在 `MAX_HEIGHT=4`，第 5 次起只改颜色，不再增加高度 |
| 拆除一格直到归零 | 高度归零且颜色清零（`colors[key] = 0`），该格回到空地状态 |
| 拆除空格 | `removeBlock()` 返回 `changed: false`，不触发任何铜钱与图鉴结算 |
| 在界外落子 | `placeBlock()` 返回 `ok:false`，不修改城镇 |
| 城镇代码被截断 / 段数不对 | `decodeTown()` 返回 null，界面提示「城镇代码无法解析」，不覆盖当前城 |
| 城镇代码里的高度超出 0–4 / 颜色索引越界 | `decodeTown()` 返回 null |
| 旧版 TS1 代码（无拓地等级） | 按拓地等级 0 还原，旧城不丢 |
| 每日岛跨天 | 当天的城归档，新的一天是新的岛（种子=日期）；当天内切模式不丢进度 |
| 存档 JSON 损坏 | `deserializeProfile()` 回退为初始档案，不抛异常，界面照常可玩 |
| 地脉位置被建筑覆盖 | 地脉仍按坐标判定，建造时倍率生效（与建筑高度无关） |
| 调色升级后颜色索引越界 | `paletteSize()` 限制可用色数；越界索引在渲染时回落到 `PALETTE[0]` |

## 交互流程

1. **首屏**：海图（SVG）+ 调色板 + 工坊商店 + 地志图鉴 + 成就 + 城镇代码栏。
2. **落子**：左键点格子 → 起楼（+1 层）→ 若命中新地标则图鉴点亮、toast 播报、铜钱入账。
3. **叠高 / 换色**：再点同一格继续叠高；先选调色板再落子可以指定颜色（键盘 1–9）。
4. **拆除**：右键直接拆，或切到「拆除模式」后左键拆。
5. **升级**：工坊商店花钱升级拓地 / 调色 / 勘测 / 营建。
6. **分享**：城镇代码栏点「复制」得到 `TS2-…`；把代码贴回去点「还原」即可载入别人的城。
7. **切换模式**：顶部按钮在「自由岛 / 每日岛」之间切换，**两边各存各的城**，切换不会丢成果。

## 打磨清单

| 项 | 现状 | 要做到 |
| --- | --- | --- |
| 拓地后刷新丢城 | 城镇代码不记拓地等级，解码按 level 0 校验长度 → 整座城被静默替换成初始岛 | 代码升到 `TS2` 并带上拓地等级；旧 `TS1` 仍可解码 |
| 切换模式永久丢城 | 模式切换直接新建岛并立刻存档，原城被覆盖 | 两种模式各存各的城，切换只换读哪一份 |
| 每日模式刷新后状态丢失 | `dailyMode` 是纯内存变量 | 模式状态持久化，刷新后仍在每日岛 |
| 还原外来城镇后白嫖「初基」 | 代码不带建造计数 | 代码带上 `builds` / `removals` |
| 解码失败无提示 | 解不出来就静默沿用初始岛 | 解析失败给 toast，明说「无法解析」，不让玩家以为城凭空消失 |
| 码格式没有演进空间 | 固定四段 `TS1-种子-高度-颜色` | 升到 `TS2` 七段，并保留旧码解码分支 |
