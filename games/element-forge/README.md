# Element Forge 元素熔炉

从**水 / 火 / 风 / 土**四个基础元素出发，把任意两个丢进熔炉，撞出新世界。
一款「合成表 + 原创合成 + 图鉴收集 + 每日灵感」的网页小游戏。

> 原创实现。玩法结构致敬元素合成类网页小游戏的通用范式（两两合成、结果确定、图鉴收集、稀有度分档），代码、文案、数据、音效均为本仓库自研自绘，不含任何第三方素材。

## 玩法

| 机制 | 说明 |
| --- | --- |
| **熔炼** | 点图鉴里的元素填入 A / B 两个槽位，点「熔炼」出结果；也可以把元素拖进槽位 |
| **合成表** | 100 多条已收录配方，结果唯一、可复现、可抄给朋友（火 + 水 = 蒸汽） |
| **原创合成** | 表里没有的组合按中文构词法拼词：取一个词的**定语**（作定语）+ 另一个词的**中心语**（作中心语），如水 + 星 → 水星 |
| **确定性** | 同一对原料永远得到同一个结果（由配方散列派生，不吃随机数），顺序无关，AB = BA |
| **稀有度** | 普通 / 稀有 / 史诗 / 传说 / 神话 五档。表内配方按设定分档；原创合成的稀有度随**合成层数**加深而提高 |
| **重名消歧** | 拼出的词撞上已有词条时自动加「增幅前缀」（超 / 巨 / 太 / 古 / 梦 / 幻）；原创词之间重名则追加序号 |
| **图鉴** | 106 个正式词条 + 不断增长的原创词条，未发现的显示为 `?`，可搜索 |
| **配方手册** | 每条熔炼成功的配方都会记下来；**点击条目可把两个原料装回熔炉原样复现** |
| **每日灵感** | 每天 5 次随机抽取，**保底**：连续 12 次未出传说及以上，下一次必出传说 |
| **成就** | 10 项：初次熔炼、元素学徒、收藏家、炼金术士、三层之境、五层之境、妙手偶得、传说制造者、神话降临、灵感常客 |
| **多语言** | 中文 / English / 日本語，右上角切换 |
| **本地存档** | 进度存 `localStorage`，刷新不丢；存档损坏时自动回退为初始状态 |

### 合成层数

基础元素是第 0 层，每合成一次 +1。层数越深，能解锁的词条越「高级」——最深可达第 10 层
（时间 → 化石 → 记忆 → 灵魂 → 意识）。

## 目录结构

```
element-forge/
├── index.html          页面骨架
├── assets/
│   ├── app.css         样式（深色炼金主题，含移动端与 reduced-motion 适配）
│   ├── app.js          表现层：渲染 / 交互 / 音效 / 持久化
│   ├── data.js         106 个词条、100+ 条配方、词素标注、增幅前缀
│   └── i18n.js         zh / en / ja 文案
├── src/
│   └── logic.js        纯逻辑层（无 DOM 依赖，全部规则在此，可完整单测）
└── test/
    ├── logic.test.mjs  44 条单元测试
    ├── smoke.test.mjs  6 条 Playwright 浏览器冒烟测试
    └── helpers.mjs     静态服务器与 Playwright 装载辅助
```

**分层约定**：`src/logic.js` 不引用任何浏览器 API，所有规则（配方命中、原创合成、词素拼词、
稀有度分布、每日保底、成就、存档序列化）都在这里，因此能被确定性地单测；`assets/app.js`
只负责把状态画到 DOM 上。

## 运行

```bash
# 任选其一
python3 -m http.server 8080     # 然后访问 http://127.0.0.1:8080/games/element-forge/
npx serve .
```

纯静态页面，无构建步骤、无运行时依赖、不引用任何外部 CDN。

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `F` | 熔炼当前两个槽位 |
| `Esc` | 清空熔炉 |
| `Tab` / `Enter` | 在图鉴元素与熔炉按钮之间移动并选择 |

## 数据说明

- `tier` 是手工分档的稀有度，不代表统计学上的出现频率；表内配方按「元素有多罕见」来分档，
  原创合成则按合成层数与权重表抽取。
- `MORPH` 里的「定语 / 中心语」拆分只影响原创合成的成品质量，未标注的词条默认用自身名称，
  拼出的词可能略显生硬——这正是「原创合成」的乐趣所在。
- 三语名称为通用常识性标注；日文名对中文复合词采用直译或惯用译法。
