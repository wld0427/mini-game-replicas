# 功能设计文档 — Element Forge 元素熔炉

## 一句话定位

把两个元素丢进熔炉、撞出新词条的确定性合成网页小游戏：表内配方可复现，表外组合按中文构词法原创造词。

## 核心玩法循环

```
       选两个已发现元素（点击图鉴 / 拖入槽位 / 键盘）
                        ↓
        ┌───────────────┴───────────────┐
   命中合成表                      表外组合
        ↓                               ↓
   固定结果（蒸汽）              定语 + 中心语 拼词
        ↓                               ↓
   稀有度按词条设定              稀有度按合成层数加权
        └───────────────┬───────────────┘
                        ↓
              结果进图鉴（正式 / 原创同列）
                        ↓
              配方记进手册（可一键复现）
                        ↓
        每日灵感补 5 个（含保底）→ 循环
```

玩家的长期目标有两层：**把 106 个正式词条收齐**，以及**用原创合成造出自己的私藏词库**。

## 状态机

游戏有且只有一个持久状态 `state`（存档内容），其余都是视图态。

| 状态字段 | 类型 | 说明 |
| --- | --- | --- |
| `collection` | `Record<id, {count, gen, tier, improvised, names, glyph}>` | 已发现词条；`improvised` 区分表内/原创 |
| `recipes` | `Record<"a+b", outId>` | 配方手册，键**顺序无关**（`recipeKey` 归一化） |
| `achievements` | `Record<id, boolean>` | 已解锁成就 |
| `stats` | `{ fusions, discoveries, improvised, dailyDraws, maxGen, tierCounts }` | 统计 |
| `daily` | `{ date, draws, pity, lastId }` | 每日灵感状态；`date` 变化即重置 |
| `coins` / `totalEarned` | number | 铜钱（本次为记录用，不参与玩法） |

视图态（不进存档）：

| 视图态 | 说明 |
| --- | --- |
| `slots` | `['aId\|null', 'bId\|null']`，两个熔炉槽位 |
| `lastResult` | 最近一次结果，用于渲染产物卡；带 `source: 'fuse' \| 'daily'` |
| `query` | 图鉴搜索词 |
| `lang` | 当前语言 |

**阶段流转**（`lastResult.source` 决定产物卡的呈现方式，这是本次修复的核心）：

```
idle ──点击图鉴/拖拽──▶ 槽位已填 ──F 或点「熔炼」──▶ 熔炼中 ──▶ 产物卡(熔炼)
  ▲                                                          │
  │                                                          ├─ 每日灵感按钮 ──▶ 产物卡(每日)
  └──────────── Esc 清空熔炉 ◀───────────────────────────────┘
```

## 数据结构

| 数据 | 位置 | 结构 |
| --- | --- | --- |
| 词条表 | `assets/data.js` `ELEMENTS` | 106 条：`{ id, zh, en, ja, glyph, tier }` |
| 合成表 | `assets/data.js` `RECIPES` | 102 条三元组 `[a, b, out]`，顺序无关 |
| 词素标注 | `assets/data.js` `MORPH` | 形如 `{ mod: {zh,en,ja}, core: {zh,en,ja} }`，未标注则回退到自身名称 |
| 增幅前缀 | `assets/data.js` `AMPLIFIERS` | 6 个，用于原创词重名消歧 |
| 稀有度 | `assets/logic.js` `TIERS` | 5 档 `n/r/sr/ssr/ur`，各带权重 |
| 层数表 | `assets/logic.js` `GENERATIONS` | 由 `computeGenerations(RECIPES, BASE_IDS)` 推导 |

## 功能清单

| ID | 功能 | 说明 | 验收标准 |
| --- | --- | --- | --- |
| F-001 | 基础元素与五档稀有度 | 4 个基础元素水火风土可作原料，全部词条带稀有度 | `ELEMENTS` 中 `water/fire/wind/earth` 存在且共 4 个基础元素；106 条词条的 `tier` 取值全部落在 `n/r/sr/ssr/ur` 五档内 |
| F-002 | 合成表命中与顺序无关 | 表内 102 条配方结果唯一 | `applyFusion(state,'water','fire')` 与 `applyFusion(state,'fire','water')` 返回的 `id` 相同，且等于 `steam` |
| F-003 | 原创合成构词 | 表外组合按「定语 + 中心语」拼词 | 对同一对原料连续两次 `applyFusion`，两次结果的 `names.zh` 字符串完全相等 |
| F-004 | 原创词重名消歧 | 撞上正式词条加增幅前缀，原创词之间重名加序号 | 同一存档内构造出两个同名原创词条时，两个词条的 `names.zh` 不相等 |
| F-005 | 原创合成稀有度随层数提高 | 层数越深越容易出稀有档 | `improvisedTierWeights(1)` 的 `n` 权重大于 `improvisedTierWeights(6)` 的 `n` 权重，且 `ssr` 权重随层数单调不降 |
| F-006 | 合成层数计算 | 基础元素 0 层，每熔炼一次 +1 | `GENERATIONS.get('water')` 等于 0，`GENERATIONS.get('steam')` 等于 1 |
| F-007 | 每日灵感抽取与上限 | 每天 5 次，优先抽未拥有的同档词条 | 同一天连续抽取时前 5 次 `result.limited` 为 false，第 6 次为 true；首次抽取的 `result.isNew` 为 true |
| F-008 | 每日灵感保底（跨日累计） | 连续 12 次未出传说及以上，下一次必出传说；保底进度跨日累计 | 跨日抽取后 `state.daily.pity` 等于前一天进度 +1 而非清零；只走真实抽取路径连抽 30 天，保底触发次数大于 0，且连续非传说抽取次数不超过 12 |
| F-009 | 图鉴收集与原创词条目 | 熔炼结果进入图鉴，正式与原创同列 | 熔炼 1 次后图鉴词条数由 4 变为 5；原创词条的 `improvised` 为 true |
| F-010 | 配方手册记录与一键复现 | 每次熔炼记录配方；点击配方条目把两个原料装回槽位 | 熔炼 2 次后 `state.recipes` 的键数为 2；点击配方条目后 A/B 槽位显示该配方的两个原料 |
| F-011 | 成就系统 | 10 项成就按进度自动解锁 | 首次熔炼后 `achievements.first_fusion` 为 true，且解锁总数为 1；重复调用不会二次解锁 |
| F-012 | 本地存档与脏数据回退 | 进度存 `localStorage`，刷新不丢，脏数据安全回退 | 序列化后反序列化，`collection` 内容完全一致；对非法 JSON 字符串反序列化后 `stats.fusions` 为 0 |
| F-013 | 多语言与图鉴呈现 | zh/en/ja 三语切换，图鉴展示 106 格 | 切到 English 后按钮文案变为 `FUSE`，图鉴格子数仍为 106 |
| F-014 | 熔炼交互的三种输入 | 点击图鉴填槽、拖拽入槽、键盘 `F` 熔炼 `Esc` 清空 | 点击图鉴芯片后 A 槽显示该词条名；按 `F` 键后熔炼计数加 1；按 `Esc` 后两个槽位均清空；芯片 `draggable` 属性为 true 且拖到槽位后该槽显示对应词条名 |
| F-015 | 每日灵感产物卡正确呈现 | 产物卡按来源分别渲染 | 每日抽取后配方行文本中不包含 `undefined`；熔炼后配方行文本形如 `配方: 水 + 火 = 蒸汽` |
| F-016 | 搜索空态文案区分 | 搜索无结果与图鉴为空用不同提示 | 搜索一个不存在的关键词时提示文案包含 `没有匹配`，与图鉴为空时的 `还没有发现` 不同 |
| F-017 | 音效反馈 | WebAudio 现场合成音效，不依赖外部音频文件 | 熔炼时创建的振荡器节点数不少于 1，且出传说档时的振荡器数量多于出普通档时 |
| F-018 | 搜索可查到未发现词条 | 搜索能命中尚未收集的词条，并以锁定态（`?`）呈现，不剧透名字 | 搜索「化石」时 `#collection .chip` 数量为 1 且该芯片带 `is-locked` 类；`#collection-meta` 同时给出命中数与未发现数；只有搜索不存在的关键词时才出现「没有匹配」提示 |
| F-019 | 产物卡链式合成 | 点击产物卡把产物装回熔炉，并给出可见提示 | 熔炼后 `#result-hint` 文本包含「继续熔炼」；点击 `#result-card` 后 A 槽显示产物名且另一槽为空 |

## 边界与异常

| 场景 | 表现 | 判定方式 |
| --- | --- | --- |
| 槽位未填满就点「熔炼」 | 按钮保持禁用，不触发任何合成 | `fuseBtn.disabled` 为 true，且 `state.stats.fusions` 不变 |
| 传入不存在的元素 id | `applyFusion` 抛出明确错误，不返回半成品状态 | 对未知 id 调用 `applyFusion` 抛出异常 |
| 每日灵感次数已用完 | 按钮禁用，提示「今日灵感已抽完」 | `daily.draws` 达到 5 时 `applyDailyDraw` 返回 `limited: true` |
| 换了一天再抽 | 每日计数与保底归零，重新给满 5 次 | `daily.date` 变化后 `daily.draws` 归 0 且 `daily.pity` 归 0 |
| 存档是损坏的 JSON | 静默回退为初始状态，不崩溃 | 对 `not json` 反序列化后 `stats.fusions` 为 0 且 `collection` 为空对象 |
| 存档里出现未知词条 id | 忽略该条，不影响其余数据 | 反序列化后 `collection` 中不含未知 id |
| 原创词与正式词条同名 | 自动加增幅前缀，正式词条不受影响 | 见 F-004 |
| 搜索无匹配 | 提示「没有匹配的元素」，图鉴为空 | 见 F-016 |
| 图鉴为空（重置后） | 提示「还没有发现任何元素」 | 见 F-016 |

## 交互流程

1. **进入**：首屏显示熔炉（两个空槽）、图鉴（106 格，未发现为 `?`）、每日灵感、成就、配方手册。
2. **选料**：点击图鉴里已发现的词条 → 填入下一个空槽（先 A 后 B）；已满则替换 A 并清空 B。
   桌面端也可把图鉴芯片拖进槽位。
3. **熔炼**：点「熔炼」或按 `F` → 产物卡弹出，显示词形、三语名、稀有度、新增角标、配方行。
4. **结果沉淀**：产物自动进图鉴（正式/原创同列），配方记进手册，手册里该配方变成可点条目。
5. **复现**：点手册里的任意配方 → 两个原料装回槽位 → 可立刻重演或改一个再试。
6. **每日灵感**：点「抽取灵感」→ 抽一个词条（每天 5 次，保底保传说），产物卡显示来源为「每日灵感」。
7. **搜索**：图鉴上方输入框过滤已发现词条；无匹配时给明确提示。
8. **语言**：右上角三语切换，图鉴、成就、按钮文案整体切换。
9. **清空**：`Esc` 清空两个槽位（不影响图鉴与存档）。

## 打磨清单

| 项 | 现状 | 要做到 |
| --- | --- | --- |
| 产物卡来源标注 | 每日灵感没有原料概念，原实现直接拼配方行导致 `undefined` | 产物卡区分「熔炼 / 每日灵感」两种来源，各自渲染正确的说明行 |
| 配方手册可复现 | 手册条目是纯文本，README 承诺的「方便复现」落空 | 条目改为可点按钮，悬停有高亮，点击装回原料并给出反馈 |
| 搜索空态 | 无匹配与图鉴为空共用一句话 | 拆成两句，避免玩家误以为进度丢失 |
| 原创词辨识 | 原创词条与正式词条视觉差异弱 | 原创词条加「原创」角标与专属底色；图鉴分组标题区分「正式词条 / 原创词条」 |
| 稀有度反馈 | 产物卡只有颜色 | 稀有度同时给文字标签（不靠颜色单独承载信息） |
| 音效 | 熔炼音阶已分档，但无实测 | 冒烟测试断言振荡器数量随稀有度递增 |
| 移动端 | 顶栏折行后语言按钮可能竖排断字 | 语言按钮 `white-space: nowrap`，顶栏允许换行 |
| 元素图标可辨识 | 雾 / 尘土 / 灰烬 / 浓雾 共用 `🌫️`，该字形在 Noto Color Emoji 下渲染成无特征白块，且 4 格同貌 | 按「同族共享字形」约定重新分配：雾 `☁️`、云 `⛅`、尘土 `🟫`、灰烬 `🖤`、浓雾 `🌁` |
| 桌面双栏配平 | 左栏（熔炉）比右栏短约 900px，桌面端右侧拉出大片空白，且配方手册与熔炉分居两栏 | `.layout` 改网格区域排布：熔炉 / 每日灵感 / 配方手册 在左，图鉴 / 成就 在右，两栏底端对齐，页面高度 1602 → 1187px |
| 提示条不遮挡 | toast 固定 `top: 122px`，窄屏顶栏折成两行后高 123px，正好压住「原料 A」槽位 | toast 改为固定底部居中，桌面端也不再压住「图鉴」标题 |
| 每日保底可达性 | 每日上限 5 次 < 保底阈值 12 次，且跨日把 `pity` 清零 → 保底永远攒不到阈值，等于死代码 | 保底进度跨日累计；补一条**只走真实抽取路径**的可达性断言（不再伪造 `pity=12`） |
| 拖拽入槽 | 代码写了 `dragstart` / `drop`，但芯片是 `<button>`，默认不可拖，`dragstart` 永不触发 | 芯片显式 `draggable=true`；补真实拖拽落槽的浏览器断言 |
| 链式合成可发现性 | 产物卡可点击继续熔炼，但 `chain_hint` 文案从未渲染，功能存在却没人知道 | 产物卡内补一行可见的「点击产物可继续熔炼」提示 |
| 搜索可查未发现词条 | 搜索只过滤已收集词条，搜到真实存在但尚未发现的元素会回「没有匹配」 | 命中未收集词条时以锁定态（`?`）展示，并报「命中 N 项 / 其中 M 项未发现」 |

## 可访问性与适配

- 槽位是真实 `<button>`，可 Tab 聚焦、Enter/Space 触发；图鉴芯片同理，未发现的用 `disabled` 表达。
- 产物卡所在区域 `aria-live="polite"`，熔炼结果与每日灵感结果都会被读屏播报。
- 稀有度用「颜色 + 文字标签」双通道表达，不靠颜色单独承载信息。
- 390px 视口无横向溢出；顶栏允许换行，语言按钮不折字。
- `prefers-reduced-motion` 下关闭入场动画与过渡。

## 明确不做的事

- **不做**多语言之外的本地化日期/数字格式。
- **不做**云端存档与账号体系（保持零依赖纯静态）。
- **不做**多人对战或排行榜（确定性玩法的价值在于可自比，不在于互比）。
- **不做**把原创词条写进词素表（那会破坏「原创」的定义边界）。
