# Angler's Almanac 渔汛录

抛竿、等待、咬钩、抢起竿时机、遛鱼收放线 —— 把整本鱼谱钓满。
一款「图鉴收集 + 随机稀有度 + 装备增量」的钓鱼网页小游戏。

> 原创实现。玩法结构致敬休闲钓鱼 / 图鉴收集类网页小游戏的通用范式（抛竿 → 咬钩窗口 → 起竿 → 遛鱼 → 收获 → 换装备 → 更深水层），
> 代码、文案、数据、音效均为本仓库自研自绘，不含任何第三方素材。

## 玩法

一轮钓鱼由**三个阶段**组成，全程可鼠标 / 触屏 / 键盘操作：

| 阶段 | 操作 | 说明 |
| --- | --- | --- |
| **抛竿** | 点「抛竿」或按 `空格` | 浮漂入水，等待咬钩（时长随饵等级变短） |
| **起竿** | 在咬钩窗口内点「起竿！」或按 `空格` | 窗口默认 1350ms，卷线器加宽、水越深越窄；**错过就跑了** |
| **遛鱼** | 标记进入绿区时点击收线 | 竖条上的标记来回摆动，绿区是「甜区」；在绿区收线降张力，乱点升张力 |

**遛鱼规则**：拉力条满 100 就断线（鱼跑了），拉到 0 以下就成功上钩。收线有 0.22s 冷却，
所以连点没用 —— 得卡在甜区上点。稀有鱼挣扎更快、甜区更窄，传说级要更准的手感。

### 收集与增量

| 机制 | 说明 |
| --- | --- |
| **鱼谱** | 44 种鱼，每种记录条数与最大个体；未发现的显示 `?` |
| **稀有度** | 普通 / 稀有 / 史诗 / 传说 / 神话 五档，各档鱼价差 3～100 倍 |
| **水层** | 饵等级决定能钓到多深：浅滩 → 近岸 → 深水 → 暗流 → 深渊，逐层解锁更高稀有度 |
| **鱼竿（幸运）** | 提高稀有档权重，让普通鱼变少、传说变多 |
| **卷线器** | 起竿窗口 +130ms/级，容错更高 |
| **饵** | 解锁更深水层：稀有，但等待更久、起竿窗口更窄 |
| **鱼篓** | 售价 +22%/级，同样的鱼更值钱 |
| **保底** | 连续 10 次没钓到当前水层最强的一档，下一竿必出那一档（换水层会重置计数） |
| **大个体** | 体长落在区间后 15% 算大个体，图鉴记录历史最大 |
| **成就** | 10 项：初次上钩、十种鱼、廿五种鱼、集齐全谱、稀有猎手、史诗现身、传说之鱼、神话降临、大个体、装备精良 |
| **多语言** | 中文 / English / 日本語，右上角切换 |
| **本地存档** | 进度存 `localStorage`，刷新不丢；存档损坏时自动回退为初始状态 |

## 目录结构

```
angler-almanac/
├── index.html          页面骨架
├── assets/
│   ├── app.css         样式（深海晨光主题，含移动端与 reduced-motion 适配）
│   ├── app.js          表现层：阶段机 / 渲染 / 交互 / 音效 / 持久化
│   ├── data.js         44 个鱼种、装备与稀有度分档
│   └── i18n.js         zh / en / ja 文案
├── src/
│   └── logic.js        纯逻辑层（无 DOM 依赖，全部规则在此，可完整单测）
└── test/
    ├── logic.test.mjs  43 条单元测试
    ├── smoke.test.mjs  Playwright 浏览器冒烟测试
    └── helpers.mjs     静态服务器与 Playwright 装载辅助
```

**分层约定**：`src/logic.js` 不引用任何浏览器 API，所有规则（抛竿节奏、起竿窗口、稀有度权重、
保底、体长与售价、遛鱼力学、装备价格、成就、存档序列化）都在这里，因此能被确定性地单测；
`assets/app.js` 只负责把状态画到 DOM 上并驱动阶段机。

## 运行

```bash
# 任选其一
python3 -m http.server 8080     # 然后访问 http://127.0.0.1:8080/games/angler-almanac/
npx serve .
```

纯静态页面，无构建步骤、无运行时依赖、不引用任何外部 CDN。

## 数据说明

- `hue` 是为每种鱼手工挑的色相，用于 CSS/SVG 自绘的鱼身配色（同一个 SVG 形状按色相上色）。
- `value` 是基础售价，实际售价 = 基础价 × 体型系数（0.7～1.3）× 鱼篓加成。
- `minCm/maxCm` 为虚构但合理的体长区间，用于体型分布与「大个体」判定，不对应真实物种数据。
- 三语名称为通用常识性标注；日文名采用该物种在日本的通用称呼。
