## 视觉与交互打磨验收

| 检查项 | 结论 | 说明 |
| --- | --- | --- |
| 张力条配色语义一致 | ✅ | **原问题**：填充条把绿→黄→红渐变铺在自身宽度上，张力 20% 时末端就已是红的（看上去像危险），而轨道自己的危险区在 62% 之后，两套红打架。现改为：轨道三段硬边界色带 + 填充条实色，颜色统一由 `logic.js` 的 `tensionZone()` 决定 |
| 同屏无重复提示 | ✅ | **原问题**：「标记进入绿区时点击收线」同时出现在场景状态区与遛鱼面板顶部。现改为：场景状态区给定性提示（松/紧/快断），遛鱼面板保留操作提示，张力标签给定量读数（拉力 %） |
| 场景信息密度 | ✅ | **原问题**：1280×250 水面场景只有一个小浮标，操作信息全挤在下方。现新增 SVG 鱼影（随张力横向移动）、二次贝塞尔钓线（张力越高越绷直）、左上角水层徽标 |
| 失败结算不误导 | ✅ | **原问题**：断线后产物卡仍完整显示「罗非鱼 / 17.4cm」，看起来像钓到了。现统一显示「跑了 / 没能钓上来」 |
| 遛鱼命中可感知 | ✅ | **原问题**：`reel.good`/`reel.pulls` 逻辑层一直在统计，表现层从不读，玩家只能靠音调猜。现加 `is-hit`/`is-miss` 标记类与「完美 ×N」连击计数 |
| 移动端无横向溢出 | ✅ | 390×844 视口 `scrollWidth - clientWidth = 0`（浏览器用例断言） |
| 文案无占位符、无 `undefined` | ✅ | 三语文案逐条核对；D-4 用例断言全页文本不含 `undefined` |
| 文案与实现一致 | ✅ | 饵的描述已由「等待更久」改为「等待更短、起竿窗口更窄」；鱼竿描述由「稀有档更容易上钩」改为「稀有及以上」（因为幸运现已覆盖 r 档） |
| 动画不喧宾夺主 | ✅ | 命中/失手为一次性反馈类，不循环；`prefers-reduced-motion` 下全部降为 0.001ms |
| 音效不刺耳 | ✅ | 全部 WebAudio 合成，正弦/方波 + 噪声，包络时长 0.1–0.4s，不加载任何音频文件 |

## 本轮（2026-11-27 审计后）修掉的真实缺陷

审计报告 `docs/audit/angler-almanac.md` 查出、且本轮**实际修复**的问题：

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| A-1 | 起竿窗口**永不判负**：`onHookTimeout` 是死代码，倒计时只写进文字不参与判定，迟到 7.5 秒仍能起竿成功 —— 「抢时机」这一玩法核心被架空 | 新增 `logic.js` `hookWindowOpen()` 纯函数作为唯一口径；`onBite` 安排超时定时器；`doHook` 入口兜底判定；`loop()` 中 `bite` 阶段直接判负。连带修复：失误统计恒为 0、「鱼跑掉了」文案不可达、**卷线器升级零作用** |
| B-1 | 饵 Lv.5 界面显示 `undefined Lv.5` | `i18n.js` `depth_name` 补第 5 项「极渊 / Deepest / 極淵」 |
| B-2 | 饵的文案「等待更久」与实现（每级缩短 90ms）相反，README 又写「时长变短」，文档自相矛盾 | 文案统一为「等待更短、起竿窗口更窄」 |
| B-3 | 鱼竿幸运只加权 n/sr/ssr/ur，**完全没有加权 r（稀有）档**，玩家按文案理解会落空 | `LUCK` 补 `rare: 0.24` 并对 `weights.r` 加权；文案改为「稀有及以上」 |
| B-4 | 断线后产物卡仍完整显示鱼种名与体长，看起来像钓到了 | 失败时统一显示 `escaped_name` / `escaped_size` |
| B-5 | 跳过链接「跳到抛竿区」硬编码中文 | 加 `data-i18n="skip_to_stage"`，三语覆盖 |
| C-2 | 遛鱼命中甜区**没有任何视觉确认**，`reel.good`/`reel.pulls` 统计了却从不被表现层读取 | `renderReel()` 加 `is-hit`/`is-miss` 类 + `#reel-combo` 完美连击计数 |
| C-3 | `stats.casts/misses/escapes` 逻辑层在记，UI 从头到尾没展示过 | 统计栏补抛竿/失手/断线三项 |
| 打磨-2 | 张力条填充条与轨道各用一套红色语义，低张力时读图被误导 | 引入 `TENSION_ZONE` / `tensionZone()` 统一口径，填充条改实色 |
| 打磨-3 | 同一屏两处重复提示 + 场景信息密度极低 | 场景区改定性提示；新增鱼影、钓线、水层徽标 |

## 门禁之外的自查

- **零构建 / 零依赖 / 零外部 CDN**：全仓无 `package.json`、无 `node_modules`、无外链资源；图标为内联 SVG data URI；音效全部 WebAudio 现场合成。
- **分层未被破坏**：`src/logic.js` 不引用任何浏览器 API（`document`/`window`/`localStorage`/`performance`），全部规则可单测；`assets/app.js` 只做渲染与事件。
- **确定性**：所有随机走 `mulberry32` 固定种子 PRNG，单测可复现。
- **可判定性**：本文件与 `docs/design.md` 的验收标准均为可被一条断言判定的形式，无「体验流畅」类表述。
