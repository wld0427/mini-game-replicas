## 本轮（2026-11-26 审计后）修掉的真实缺陷

审计报告 `docs/audit/kanji-rush.md` 查出、且本轮**实际修复**的问题：

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| A-1 | 成就「十五连击」概率 1.9e-13，玩家永远拿不到，是死代码 | 连击规则由「史诗+」改为「稀有+」（实测 50/200/1000 抽分别可达 3/5/8 连），成就改为三/五/八连击三级里程碑，并新增**可达性回归测试** |
| B-1 | `is-fever` 的 `animation` 简写整体覆盖了翻卡动画，最稀有两档反而没有翻卡演出 | 改为 `animation: card-in …, fever …` 组合写法，并用计算样式断言守住 |
| B-2 | 「最近抽取」日志不随存档持久化，刷新即清空 | 序列化带上 log（限 30 条），反序列化过滤未知 kanjiId |
| B-3 | 同帧解锁多个成就只提示第一个 | 合并为一条文案，多个成就名以 `·` 连接 |
| B-4 | 反序列化不校验收藏 key，伪造 id 即可解锁「藏家」 | 引入真实汉字 id 白名单（未注册时宽松降级，避免误清空玩家进度） |
| B-5 | 重置进度后卡面残留 fever 辉光 | `resetAll` 清理 `is-pulling` / `is-fever` |
| C-1 | 分档抽取次数有数据无 UI | 新增分档分布条（F-012） |
| C-2 | 加速（surge）状态无提示 | 新增加速徽标（F-014） |
| C-3 | 成就不说明达成条件 | 每个成就补三语条件文案与目标进度（F-013） |
| C-4 | 自动模式与空格键叠加抽卡，实际节奏与显示的间隔对不上 | 自动模式下忽略空格 |
| D-1 | 无任何测试断言成就可达 | 新增可达性回归测试（20000 次真实抽取路径） |
| D-2 | 存档往返漏了 log | log 纳入往返断言 |
| D-3 | 表现层关键分支无测试 | 补动画计算样式、重置流程等行为断言 |
| D-4 | 自动模式只断言计数增长 | 补自动+空格去重断言 |

修复过程中还暴露了**两个我自己引入的新 bug**，均由新增测试当场抓住：
`surge-badge` 的 `display:inline-block` 覆盖了 `[hidden]` 的 UA 样式；
`renderStats` 的 `textContent` 赋值把徽标元素整个覆盖掉。

## 已知问题

- `freq` 字段是手工归类的"生僻度百分位"，不是严格的语言学频率统计。不影响核心玩法，
  但如果玩家较真会与真实维基频率表有出入。已在 README 与设计文档中如实标注。
- 无排行榜、无多端存档同步。属"明确不做的事"范围，不影响核心玩法。
- 图鉴仍是 102 格全量平铺的长列表，移动端成就与日志仍在首屏之外（需要独立滚动容器才能根治）。
  属打磨项，未在本轮处理，已记入 `docs/audit/kanji-rush.md` 的 P2。
