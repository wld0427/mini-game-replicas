## 已知问题

- `freq` 字段是手工归类的"生僻度百分位"，不是严格的语言学频率统计。不影响核心玩法，
  但如果玩家较真会与真实维基频率表有出入。已在 README 与设计文档中如实标注。
- 无排行榜、无多端存档同步。属"明确不做的事"范围，不影响核心玩法。
