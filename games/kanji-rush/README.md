# Kanji Rush

按真实使用频次决定稀有度的**汉字扭蛋**网页小游戏。抽得越多，演出节奏越快。

> 原创实现。玩法结构致敬「漢字ガチャ」类网页小游戏的通用范式（频次定稀有度 / 越抽越快的演出节奏 / 图鉴收集 / 保底机制），代码、文案、素材、音效均为本仓库自研自绘，不含任何第三方素材。

## 玩法

| 机制 | 说明 |
| --- | --- |
| **稀有度** | 每个汉字带一个「生僻度百分位」`freq`（0–100，越大越生僻），据此落入 5 个档位：普通 / 稀有 / 史诗 / 传说 / 神话 |
| **抽取** | 点击「抽取」或按 `空格` 出一张字卡，演出带翻卡动画与合成音效 |
| **越抽越快** | 抽取间隔随抽卡数递减（1400ms → 180ms 下限），命中传说以上时进入 5 次 20% 加速 |
| **保底** | 连续 60 次未出传说及以上，下一次必出传说（Pity） |
| **连击** | 连续抽到稀有及以上累计连击，普通清零；里程碑 3/5/8 连（实测 50/200/1000 抽内可达） |
| **图鉴** | 102 个汉字的收集面板，重复获得会累计数量 |
| **成就** | 11 项成就：初次抽取、藏家、常用字通、欧皇、神话猎手、三/五/八连击、百抽达成、极速档、保底突破 |
| **多语言** | 中文 / English / 日本語，右上角切换 |
| **本地存档** | 进度存 `localStorage`，刷新不丢；存档损坏时自动回退为初始状态 |

## 目录结构

```
kanji-rush/
├── index.html          页面骨架
├── assets/
│   ├── app.css         样式（深色 + 稀有度配色，含移动端与 reduced-motion 适配）
│   ├── app.js          表现层：渲染 / 交互 / 音效 / 持久化
│   ├── data.js         字库（102 字，含读音与双语释义）
│   └── i18n.js         zh / en / ja 文案
├── src/
│   └── logic.js        纯逻辑层（无 DOM 依赖，全部规则在此，可完整单测）
└── test/
    ├── logic.test.mjs  19 条单元测试
    ├── smoke.test.mjs  Playwright 浏览器冒烟测试
    └── helpers.mjs     静态服务器与 Playwright 装载辅助
```

**分层约定**：`src/logic.js` 不引用任何浏览器 API，所有规则（稀有度判定、权重抽取、保底、节奏、成就、存档序列化）都在这里，因此能被确定性地单测；`assets/app.js` 只负责把状态画到 DOM 上。

## 运行

```bash
# 任选其一
python3 -m http.server 8080     # 然后访问 http://127.0.0.1:8080/games/kanji-rush/
npx serve .
```

纯静态页面，无构建步骤、无运行时依赖。

## 测试

```bash
cd games/kanji-rush
node --test "test/*.test.mjs"
```

- **单元测试**：使用固定种子的 mulberry32 PRNG，结果可复现；覆盖权重分布（3000 次采样 + 容差断言）、保底触发与计数、节奏单调性、连击规则、成就不重复解锁、存档往返与脏数据回退。
- **冒烟测试**：真实 Chromium 中验证首屏渲染、点击/空格两种抽取方式、自动模式连续抽取、语言切换、刷新后进度保留、控制台零报错，以及 390px 移动端视口无横向溢出。

需要 Playwright：`npm i -D playwright && npx playwright install chromium`（沙箱环境已预装）。

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `空格` | 抽取一次 |
| `A` | 开/关自动抽取 |

## 数据说明

`freq` 字段是手工归类的「生僻度百分位」，用于稀有度分档，不代表严格的语言学频率统计。读音与释义为通用常识性标注。
