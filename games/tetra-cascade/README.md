# Tetra Cascade 无尽方块

七袋随机、消行连击、等级加速 —— 再加一本**方块图鉴**。
经典下落消行玩法，全部代码 / 文案 / 图形 / 音效原创自绘。

> 原创实现。玩法结构致敬经典下落消行类网页小游戏的通用范式（7-bag 随机 / 旋转踢墙 / 暂存 / 幽灵块 / 消行计分 / 等级加速），
> 代码、文案、数据、音效均为本仓库自研自绘，不含任何第三方素材。
> **旋转态与踢墙表均为自研**，未使用任何商业版本的旋转系统数据。

## 玩法

| 机制 | 说明 |
| --- | --- |
| **棋盘** | 10 × 20，7 种四格方块（长条 / 左钩 / 右钩 / 方块 / 蛇形 / 梅花 / 反蛇） |
| **7-bag 随机** | 每袋七种各一，打乱后依次发出 —— 同一种方块绝不会连续缺席超过 12 块 |
| **幽灵块** | 半透明预览显示当前方块的落点 |
| **暂存** | 按 `C` / `Shift` 把当前方块存起来，之后可与新方块交换（每块只能用一次） |
| **旋转踢墙** | 贴边旋转会被踢墙救回（自研简化踢墙表：0 / ±1 / ±2 列） |
| **锁定延迟** | 落地后有 0.5s 缓冲，期间可微调位置；最多续命 15 次 |
| **消行计分** | 单行 100 / 双行 300 / 三行 500 / 四行 800，再乘等级；连消额外 `50 × 连击 × 等级` |
| **软降 / 硬降** | 软降每格 +1，硬降每格 +2 并立即锁定 |
| **等级加速** | 每消 10 行升一级，下落间隔从 1000ms 一路压到 60ms 下限 |
| **方块图鉴** | 7 种方块各 3 条里程碑（共 21 条）：初次登场 / 熟手（用满 20 次）/ 名手（用它消 3 行） |
| **成就** | 8 项全局成就：初次落子、首消达成、四行齐消、五连消、百行成就、十级速降、万分达成、全谱收藏 |
| **今日挑战** | 同一天所有玩家拿到**同一条方块序列**（日期做种子），方便比较当日成绩 |
| **多语言** | 中文 / English / 日本語，右上角切换 |
| **本地存档** | 图鉴 / 纪录 / 成就存 `localStorage`，**中途刷新也不丢进度**；存档损坏时自动回退 |

## 目录结构

```
tetra-cascade/
├── index.html          页面骨架
├── assets/
│   ├── app.css         样式（深色霓虹主题，含移动端与 reduced-motion 适配）
│   ├── app.js          表现层：帧循环 / 输入（键盘 + 触控）/ 渲染 / 音效 / 持久化
│   ├── data.js         7 种方块的 4 个旋转态、配色、评分表、里程碑
│   └── i18n.js         zh / en / ja 文案
├── src/
│   └── logic.js        纯逻辑层（无 DOM 依赖，全部规则在此，可完整单测）
└── test/
    ├── logic.test.mjs  39 条单元测试
    ├── smoke.test.mjs  Playwright 浏览器冒烟测试
    └── helpers.mjs     静态服务器与 Playwright 装载辅助
```

**分层约定**：`src/logic.js` 不引用任何浏览器 API，所有规则（碰撞、旋转踢墙、7-bag、消行、
计分与连击、等级与重力、锁定延迟、暂存、游戏结束判定、图鉴与里程碑、成就、存档）都在这里，
因此能被确定性地单测；`assets/app.js` 只负责把状态画到 DOM 上并驱动帧循环。

> **一个刻意的例外**：对局对象（棋盘 / 当前方块 / 队列）是**可变**的。
> 它每帧都在变，整块复制棋盘纯属浪费。所有逻辑函数只读写传入的对局对象，不碰浏览器 API，
> 因此依然可完整单测。而**档案对象**（图鉴 / 纪录 / 成就）是不可变的，每次更新返回一份新档案。

## 运行

```bash
# 任选其一
python3 -m http.server 8080     # 然后访问 http://127.0.0.1:8080/games/tetra-cascade/
npx serve .
```

纯静态页面，无构建步骤、无运行时依赖、不引用任何外部 CDN。

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `←` `→` / `A` `D` | 左右移动（长按自动连发） |
| `↓` / `S` | 软降 |
| `↑` / `X` | 顺时针旋转 |
| `Z` / `Ctrl` | 逆时针旋转 |
| `空格` | 硬降 |
| `C` / `Shift` | 暂存方块 |
| `P` / `Esc` | 暂停 / 继续 |

移动端使用屏幕下方的触控按钮。

## 数据说明

- `states` 是 4 个旋转态的**格坐标**，全部按「同一形状在方框内旋转 90°」机械生成并由单测守护，
  不是手抄的表。
- `value`（计分表）与等级倍率沿用下落消行的通用惯例，便于与同类游戏横向比较。
- 三语名称为通用常识性标注；「方块图鉴」里的里程碑名称为原创撰写。
