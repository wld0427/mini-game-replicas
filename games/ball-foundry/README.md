# Ball Foundry 落球坊

往罐子里丢球，让它们弹跳、碰撞、堆成一坨。
一款**确定性物理沙盒** + 材质图鉴收集的网页小游戏。

> 原创实现。玩法结构致敬物理弹球 / 增量经营类网页小游戏的通用范式（投放 → 物理堆叠 → 结算 → 升级 → 更深的材质池），
> 代码、文案、数据、音效均为本仓库自研自绘，不含任何第三方素材。
> **物理是手写定步长模拟**，没有用任何物理库。

## 玩法

| 机制 | 说明 |
| --- | --- |
| **投放** | 点击罐子任意位置落球，或按 `空格`；也可以开自动投放 |
| **物理** | 定步长（1/120 s）模拟：重力、线性阻尼、弹性、摩擦、球球碰撞、位置修正 + 冲量解算 |
| **材质** | 7 种：橡皮（弹）／铁（重）／黏（黏住）／玻璃（极弹）／火（撞击爆裂）／磁（吸引邻球）／金（稀有高价） |
| **结算** | 球静止即「落定」，按材质折算铜钱 |
| **升级** | 加宽容器 / 加高容器 / 自动投放器 / 解锁材质 —— 每一项都直接改物理参数或掉落池 |
| **保底** | 连续 12 颗没抽到当前能抽到的最好一档，下一颗必出那一档（换水层后保底重置） |
| **材质图鉴** | 7 种材质 × 3 条里程碑 = 21 条收集物（初次登场 / 常客 / 收藏家） |
| **结束** | 堆到投放线即本局结束，自动记录本局成绩 |
| **多语言** | 中文 / English / 日本語，右上角切换 |
| **本地存档** | 图鉴 / 纪录 / 成就存 `localStorage`，中途刷新不丢进度；存档损坏时自动回退 |

### 为什么物理是「确定性」的

固定步长 `dt = 1/120`，每帧推进的步数由累加器换算，**不依赖真实帧时长**。
同一个初始状态 + 同一串操作 → 逐位相同的结果。所以物理可以逐帧单测：
球该停在哪、该弹多高、会不会互相穿透、磁球会不会把球吸穿，全部是断言而不是「看着差不多」。

## 目录结构

```
ball-foundry/
├── index.html          页面骨架
├── assets/
│   ├── app.css         样式（暖色工坊主题，含移动端与 reduced-motion 适配）
│   ├── app.js          表现层：帧循环 / 渲染 / 输入 / 音效 / 持久化
│   ├── data.js         7 种材质的物理参数、升级配置、图鉴里程碑
│   └── i18n.js         zh / en / ja 文案
├── src/
│   └── logic.js        纯逻辑层（无 DOM 依赖，全部规则在此，可完整单测）
└── test/
    ├── logic.test.mjs  39 条单元测试
    ├── smoke.test.mjs  Playwright 浏览器冒烟测试
    └── helpers.mjs     静态服务器与 Playwright 装载辅助
```

**分层约定**：`src/logic.js` 不引用任何浏览器 API。物理、掉落、保底、图鉴、成就、存档、
手感层（抖动 / 打击停顿）全在这里，因此能被确定性地单测；`assets/app.js` 只负责
把状态画到 SVG 上并驱动帧循环。

### 手感层也放在逻辑层

抖动与打击停顿是「判定」而非「表现」：创伤值按 `trauma²` 映射到抖动幅度、
用真实时间衰减；打击停顿缩放物理时间轴但**不冻结抖动衰减**。
把它们放进 `logic.js` 之后，「同一事件 30ms 内触发两次，时间倍率必须回到 1.0」
这类检查可以直接写成单测。

## 运行

```bash
# 任选其一
python3 -m http.server 8080     # 然后访问 http://127.0.0.1:8080/games/ball-foundry/
npx serve .
```

纯静态页面，无构建步骤、无运行时依赖、不引用任何外部 CDN。

## 测试

```bash
cd games/ball-foundry
node --test "test/*.test.mjs"
```

- **单元测试**（39 条）：材质参数合法性与质量比、容器尺寸随升级、材质解锁阶梯、
  保底休眠 / 触发 / 计数清零、掉落权重分布（2 万次采样）、**物理确定性**
  （同输入同输出）、**帧率无关**（不同帧率步数差 ≤ 1 且余量保留）、
  **卡顿保护**（单帧步数有上限、速度不超上限）、**防穿模**（单步位移 < 最小半径）、
  堆叠不穿透、沉睡与唤醒、磁球吸引且不吸穿、作用范围外不吸引、火球爆裂并推动邻居、
  弹性差异（橡皮 > 铁 > 黏）、投放点占用与球数上限、溢出判定、
  图鉴与里程碑、成就、升级价格与上限、**手感层自检**（创伤归零时间、打击停顿恢复、
  抖动平方映射）、**性能预算**（满罐 120 步耗时上限）、存档往返与脏数据容错、边界输入。
- **冒烟测试**：真实 Chromium 中验证首屏渲染（7 种材质 / 4 项升级 / 8 条成就）、
  点击投放、球落定后结算铜钱、图鉴记录、键盘投放 / 清空 / 自动切换、
  语言切换、刷新后图鉴与铜钱保留、控制台零报错，以及 390px 移动端视口无横向溢出。

需要 Playwright：`npm i -D playwright && npx playwright install chromium`（沙箱环境已预装）。

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `空格` | 投放一颗球 |
| `A` | 开 / 关自动投放 |
| `C` | 清空罐子 |

移动端直接点击罐子投放；设置面板可调「抖动强度」与「减少动效」。

## 数据说明

- 物理参数（半径 / 质量 / 弹性 / 摩擦 / 售价）为手工调校的通用量级，
  单位是「世界单位」，不映射到真实物理单位。
- `depth`（投放线）决定了堆到多高算满罐；容器变高只是把这条线往上挪，
  堆叠的玩法本身不变。
- 三语名称为通用常识性标注；里程碑名称为原创撰写。
